PUBLICERING
============

1. Packa upp ZIP-filen.
2. Öppna index.html lokalt för att kontrollera sidan.
3. Ladda upp index.html, style.css och hela mappen images till webbhotellets publika mapp (ofta public_html eller www).
4. Behåll samma mappstruktur.

INNAN PUBLICERING
=================

Sök efter kontakt@example.com i index.html och ersätt den med din e-postadress.
Den transparenta loggan för Poka-yoke Engineering finns i images/PYE_logo.png.

Sidan är helt statisk och kräver varken databas, PHP eller Node.js.
